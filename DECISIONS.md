# Технические решения — фактический статус

Проект X2609-382, CodeBY. Состояние после локального исправления baseline `9442a0f`.

## Реализовано

- TypeScript-расширение VS Code запускает Go-процесс. JSON-RPC 2.0, одна JSON-строка на сообщение, stdio; логи только в stderr. Перезапуск при изменении конфигурации исключает повторный initialize во время индексации.
- Pure-Go SQLite `modernc.org/sqlite`, без CGO; база в `storageUri`. Векторы float32 BLOB, FTS5 `unicode61`. Вес символа 10, контекста 5, тела 1; служебные поля имеют вес 0.
- Косинусное сходство по всем чанкам в памяти и RRF: k=60, vector weight=1, BM25 weight=0.6. Для отсутствующего BM25 применяется штрафной ранг `число чанков + 50`, а не стандартный нулевой вклад. Этот вариант требует оценки с IR-экспертом. Порог релевантности отсутствует.
- Чанкинг C#/TS/JS/Go — регулярные выражения и скобочные эвристики. C# дополнен маскированием строк/комментариев и поддержкой типичных многострочных/generic/expression-bodied методов. Есть контекст и документация, но это не полноценный синтаксический разбор. Python и неопознанные конструкции — окна по 80 строк с перекрытием 15. Приближённое усечение C# embedding input до бюджета 1024 токена не является точной токенизацией.
- SHA-256 файлов пропускает неизменившиеся файлы; SHA-256 фактического embedding input позволяет переиспользовать неизменившиеся чанки предыдущего индекса. Замена чанков, FTS и файлового хеша — одна транзакция. Пустые и удалённые файлы очищаются.
- Watcher создания/изменения/удаления (переименование наблюдается как delete/create), debounce 600 мс, один индексатор с объединением следующего прохода. Сканируется первая рабочая папка, сохранённые файлы, фиксированный список исключений; `.gitignore` не реализован.
- Отпечаток workspace + URL + модели + версии чанкинга очищает несовместимый индекс при initialize; ключ исключён. Размерность проверяется; force-reindex очищает индекс, в том числе для замены модели под тем же именем. При таком сбросе старый индекс не сохраняется как резервный.
- OpenAI-совместимый HTTP API с необязательным ключом, проверкой ответа, размерности и конечности векторов. Ошибки 401/403/429 сохраняются, без автоматических повторов и без вывода тела ответа с потенциальными секретами.
- QuickPick с debounce 350 мс, одной активной отправкой поиска, защитой от устаревших ответов, alwaysShow, превью и переходом по исходным строкам. Боковая панель хранит полный список и исходный запрос до перезапуска/смены конфигурации.
- Явный opt-in `enabled=false` по умолчанию и доверенная workspace. Платформенный VSIX содержит движок; скрипты сборки и F5. Нет автоматического скачивания моделей или движка из рабочего проекта.

## Подготовлено, но не подтверждает качество модели

Открытое MIT C#-демо с 12 методами и 30 запросами (RU, EN, symbol), оценщик Hit@5/Recall@5/MRR@10, p50/p95 end-to-end задержки и времени индексации. Прогон с локальным mock проверяет механизм оценки. Реальный провайдер пока не согласован и не запускался.

## Запланировано / требует решения

Language Services (`executeDocumentSymbolProvider`) и Tree-sitter не подключены и не являются зависимостями. Подключать сложный парсер следует при измеренной необходимости. Не реализованы ANN/sqlite-vec, квантование, серверный индекс, HyDE, multi-root и сохранение индекса при полном сбросе. Публикация в Marketplace и платформы кроме macOS arm64 не проверены.

Необходимо согласовать с заказчиком архитектуру TypeScript + Go при TypeScript в паспорте, модель и допустимое место обработки кода, критерии качества/задержки и поддерживаемые языки. Веса RRF и бюджет чанка пока baseline, а не результат оптимизации.
