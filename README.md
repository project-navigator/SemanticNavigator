# Semantic Navigator (Семантический навигатор)

[![License: MIT](https://img.shields.io/badge/License-MIT-yellow.svg)](https://opensource.org/licenses/MIT)

> **Проект P2609-382:** Расширение для VS Code для семантического поиска по кодовой базе с использованием векторных эмбеддингов, полнотекстового поиска SQLite FTS5 BM25 и гибридного ранжирования Reciprocal Rank Fusion (RRF).

---

## 🚀 Возможности

- **Семантический поиск на естественном языке**: находите нужный код по смысловому описанию (в том числе на русском языке к коду на английском).
- **Двухкомпонентная архитектура**:
  - Высокопроизводительный движок на **Go**, работающий локально.
  - Нативное расширение для **VS Code** на **TypeScript**.
  - Связь через легковесный **JSON-RPC 2.0 по stdio** (без открытых сетевых портов).
- **Language-aware чанкинг**: семантическое разбиение на уровне методов и классов для **C#**, **TypeScript/JavaScript** и **Go** с сохранением контекста (`Namespace > Class > Method`) и XML/JSDoc комментариев.
- **Гибридный поиск (Hybrid RRF)**: слияние плотных векторных эмбеддингов (косинусное сходство) и нативного лексического поиска **SQLite FTS5 BM25** для точного поиска идентификаторов.
- **Инкрементальная индексация**: отслеживание SHA-256 хешей файлов для пересчета только изменившихся фрагментов.
- **Удобный Developer Experience (DX)**:
  - Быстрый клавиатурный поиск через **QuickPick** (`Cmd+Alt+F` / `Ctrl+Alt+F`) с превью сниппетов и живой подсветкой в редакторе.
  - Постоянная боковая панель с деревом результатов.
  - Ненавязчивая индикация прогресса индексации в **Status Bar** без блокировки редактора.
- **Поддержка любых OpenAI-совместимых провайдеров эмбеддингов**: OpenAI API, Ollama, LM Studio, vLLM или внутренний шлюз компании.

## 🛠 Сборка и запуск

### Требования
- **Go** 1.22+
- **Node.js** 18+ и **npm**
- **VS Code** 1.85+

### Быстрая сборка всех компонентов

```bash
./scripts/build.sh
```

Или по отдельности:

```bash
# 1. Сборка Go-движка
cd engine
go build -o bin/semantic-engine ./cmd/engine

# 2. Сборка TypeScript расширения
cd ../extension
npm install
npm run compile
```

### Запуск в режиме отладки

1. Откройте директорию проекта в VS Code.
2. Откройте файл `extension/src/extension.ts`.
3. Нажмите `F5` — откроется новое окно `Extension Development Host` с активированным расширением.

## ⚙️ Настройки расширения

В настройках VS Code (`Settings -> Extensions -> Semantic Navigator`):

| Параметр | По умолчанию | Описание |
|---|---|---|
| `semanticNavigator.providerUrl` | `https://api.openai.com/v1` | URL OpenAI-совместимого эндпоинта эмбеддингов |
| `semanticNavigator.apiKey` | `""` | API-ключ для доступа к провайдеру эмбеддингов |
| `semanticNavigator.model` | `text-embedding-3-small` | Название модели эмбеддингов |
| `semanticNavigator.enginePath` | `""` | Опциональный путь к кастомному бинарнику движка |
