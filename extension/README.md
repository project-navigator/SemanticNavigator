# Semantic Navigator — CodeBY

Расширение VS Code для поиска фрагментов кода по описанию обычным текстом. Проект X2609-382, MIT. Локальный Go-движок включён в платформенный VSIX; отдельно устанавливать Go пользователю пакета не требуется.

В доверенной рабочей папке откройте настройки `semanticNavigator`, задайте `providerUrl` (базовый адрес OpenAI-совместимого API), `model` и при необходимости `apiKey`. Затем включите `semanticNavigator.enabled`. До включения код не отправляется. Ключ необязателен только для провайдера, который допускает работу без авторизации. Движок добавляет `/embeddings` к URL.

После `Index ready` нажмите Cmd+Alt+F (macOS) / Ctrl+Alt+F (Windows/Linux), введите описание, выберите результат стрелками и нажмите Enter. Полная выдача с исходным запросом остаётся в боковой панели Semantic Navigator. Сохранённые изменения, создание, удаление и переименование обновляют индекс с задержкой. При смене URL или модели выполняется сброс несовместимого индекса.

HTTP 401/403: проверьте ключ и права. HTTP 429: проверьте квоту и повторите позже. Сетевая ошибка: проверьте URL и доступность сервера. Ошибка индекса открывает настройки по нажатию на статус-бар; после исправления выполните `Semantic Navigator: Reindex Workspace`. Подробности — Output → Semantic Navigator. Если движок завершился, проверьте `enginePath` и выполните Reload Window.

Работает с первой папкой workspace; C#/TS/JS/Go извлекаются эвристиками, Python и неопознанный синтаксис — окнами строк. Language Services и Tree-sitter не подключены. Индекс хранится локально, но тексты чанков и запросов отправляются выбранному провайдеру. RU→EN качество зависит от модели и пока не измерено на реальном провайдере. Score ранжирования не является вероятностью релевантности.

Исходники, инструкции сборки, набор из 30 размеченных запросов, методика оценки и сценарий демонстрации находятся в репозитории [project-navigator/SemanticNavigator](https://github.com/project-navigator/SemanticNavigator).
